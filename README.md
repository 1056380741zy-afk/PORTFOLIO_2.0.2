# Suha Yan Zhu Portfolio

This is a Vite React TypeScript portfolio with bilingual content, draggable cards, project pages, and an AI chat backed by a Netlify Function.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Start the Vite live preview:
   `npm run dev:frontend`
3. Open the local or forwarded preview URL shown in the terminal.
4. Save a file and confirm Vite hot reload updates the page.

For full local chat development, set `DEEPSEEK_API_KEY` in a local `.env` file and run:

`npm run dev`

On Netlify, set `DEEPSEEK_API_KEY` in the Netlify environment variables. Do not expose it through Vite frontend variables.
